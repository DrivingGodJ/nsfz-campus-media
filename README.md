# 附中影像 · 图片库

[附中影像主站](https://drivinggodj.github.io/nsfz-campus-gallery/)使用的公开照片资源。程序与校园模型保存在[主站仓库](https://github.com/DrivingGodJ/nsfz-campus-gallery)。

主站通过 GitHub 原始文件地址读取这里的图片，本仓库不开启 GitHub Pages。

每张照片包含缩略图、深度图、次高清展示图和下载 JPEG。下载 JPEG 不超过 5 MB。导入的私有源文件及压缩前备份仅保存在本地。
