# 附中影像 · 图片库

保存[附中影像](https://drivinggodj.github.io/nsfz-campus-gallery/)的公开照片资源与备份。程序、校园模型和照片资料由[主站仓库](https://github.com/DrivingGodJ/nsfz-campus-gallery)维护。

## 资源内容

每张照片包含缩略图、深度图、次高清展示图和可下载 JPEG。下载 JPEG 不超过 5 MB，可能经过压缩；导入的私有源文件与压缩前备份不在本仓库公开分发。

## 使用方式

浏览和下载请前往主站查看照片资料。本仓库不启用 GitHub Pages；主站的公开图片当前由 Cloudflare 静态托管提供，此处保留公开资源备份。

导入、生成图片和发布流程见主站的[维护文档](https://github.com/DrivingGodJ/nsfz-campus-gallery/blob/main/docs/MAINTENANCE.md)。
