# NSFZ Campus Gallery · Media

Public photo assets and backups for [NSFZ Campus Gallery](https://drivinggodj.github.io/nsfz-campus-gallery/). The application, campus model and photo metadata are maintained in the [main repository](https://github.com/DrivingGodJ/nsfz-campus-gallery).

## Contents

Each photo has a thumbnail, depth map, display preview and downloadable JPEG. Download JPEGs are capped at 5 MB and may be compressed. Private imported originals and pre-compression backups are not publicly distributed here.

## Usage

Use the main website to browse photo details and download images. GitHub Pages is not enabled for this repository. Public images are currently served through Cloudflare static hosting; this repository retains public asset backups.

For import, image generation and publishing, see the main repository's [maintenance guide (Chinese)](https://github.com/DrivingGodJ/nsfz-campus-gallery/blob/main/docs/MAINTENANCE.md).
